# Security Policy

This repository builds a static website with no server-side runtime, database,
or user authentication. The deployed artifact is static HTML, CSS, and images.

## Reporting a vulnerability

Please report suspected vulnerabilities through GitHub's private vulnerability
reporting: open the repository's **Security** tab and choose
**Report a vulnerability**. This keeps the report confidential until a fix is
published.

Since this is a personal project, responses are best-effort. Please allow a
reasonable window before any public disclosure.
